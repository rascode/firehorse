Components that fit wherever you put them.

Firehorse is the design system behind rascode.dev, rebuilt as an open package. Every component sizes itself to the box it's in, not the screen. Drop a card into a sidebar, a modal or a full-width grid and it lays itself out. You don't write breakpoints.

00 Principles

Six rules the whole system follows

  1. Container-native

    Components query the slot they sit in. Viewport media queries are reserved for user preferences and print.

  2. Layered

    Eight cascade layers. Your unlayered CSS always wins, so overrides never need !important.

  3. Scheme-aware

    Every color role is a light-dark() pair. One attribute flips a page, or a single card.

  4. Native first

    <details>, <dialog> and popovers do the work. Keyboard and screen-reader behavior come from the browser.

  5. Accessible by default

    Every text token clears WCAG AA on its canvas. Focus is always visible. Motion is opt-in.

  6. Agent-ready

    Ships with an agent contract, llms.txt and a token manifest, so a coding agent builds on-system the first time.

13 Themes

Pick a horse. The whole site changes.

A theme is every design decision in one file: type, color in light and dark, corner radius, density, and how avatars, cards, buttons, chips and tables look. Apply it with one attribute, data-fh-theme, and switch it with a dropdown. Firehorse ships three to start. Build your own on top of Firehorse the same way.

A native select. firehorse.js sets data-fh-theme on <html> and remembers it.

14 Adaptive color

Text that reads its background. Math, not JavaScript.

Every text and tone token is computed from the surface under it with CSS relative color: lightness is offset from the background's own OKLCH lightness and clamped, so paint any color and the text, muted text, links and nine tones re-derive to pass contrast. 17 Structured data

Schema-ready: the page and its metadata always match

Mark a component with data-schema and Firehorse builds the matching Schema.org JSON-LD from what's on the screen, then checks that the two agree. Search engines and AI systems read the same facts your visitors see.

  • Generated from the visible content, so it can't drift
  • Checks required properties, prices, currencies and positions
  • Fails the build when the JSON-LD and the page disagree
  • Never invents reviews, ratings or people

Firehorse FAQ · published as FAQPage

Is Firehorse free to use?

Yes. It's MIT licensed, so you can use it in personal and commercial projects, change it and ship it.

Do I need JavaScript?

No. Every component works with HTML and CSS alone. The optional firehorse.js adds the floating bar's engage timing, carousel controls, scroll spy and the aria wiring for form errors.

Which browsers does it support?

The main build targets current browsers: Chrome 123, Firefox 128 and Safari 17.5 and newer. A compat build covers Chrome 108 and Safari 16.4 with simpler fallbacks.

Can I use it with React, Vue or Tailwind?

Yes. Firehorse is plain CSS classes and custom properties, so it works with any framework or none, and next to Tailwind if you already use it.

How do I hand it to an AI agent?

Point the agent at firehorse.rascode.dev/llms.txt and tell it to use only fh-* classes and --fh-* tokens. The agent contract covers the rest, including structured data.

Does it handle Schema.org structured data?

Yes. Add data-schema to breadcrumbs, FAQs, pricing, service cards, steps, people or articles, then run npx firehorse-schema --write. It builds the JSON-LD from the page and checks that the two match.

    Pro skill · firehorse-builder

    Hand it a URL. Get a design system back.

    The builder is an agent skill. Give it one reference site and it reads the sitemap, visits the key pages, screenshots them at three widths in light and dark, measures the real colors, type, spacing, radii and shadows, maps them onto Firehorse roles, checks contrast, and writes a theme, a config and a preview page you can open.

    1. Crawl

      robots.txt and sitemap.xml, then a sample of each page type.

    2. Capture

      Screenshots at 390, 768 and 1440 px; computed styles from the live DOM.

    3. Extract

      Clusters colors, type scale, spacing, radii and shadows into tokens.

    4. Map

      Fits the tokens to Firehorse roles, tones and config presets.

    5. Verify & ship

      Runs the contrast and schema checks, then writes theme, config and a preview.
