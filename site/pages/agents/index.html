02 Structured data

Schema-ready: the page and its metadata always match

Mark a component with data-schema and Firehorse builds the matching Schema.org JSON-LD from what's on the screen, then checks that the two agree. Search engines and AI systems read the same facts your visitors see.

  • Generated from the visible content, so it can't drift
  • Checks required properties, prices, currencies and positions
  • Fails the build when the JSON-LD and the page disagree
  • Never invents reviews, ratings or people

Firehorse FAQ · published as FAQPage

Is Firehorse free to use?

Yes. It's MIT licensed, so you can use it in personal and commercial projects, change it and ship it.

Do I need JavaScript?

No. Every component works with HTML and CSS alone. The optional firehorse.js adds the floating bar's engage timing, carousel controls, scroll spy and the aria wiring for form errors.

Which browsers does it support?

The main build targets current browsers: Chrome 123, Firefox 128 and Safari 17.5 and newer. A compat build covers Chrome 108 and Safari 16.4 with simpler fallbacks.

Can I use it with React, Vue or Tailwind?

Yes. Firehorse is plain CSS classes and custom properties, so it works with any framework or none, and next to Tailwind if you already use it.

How do I hand it to an AI agent?

Point the agent at firehorse.rascode.dev/llms.txt and tell it to use only fh-* classes and --fh-* tokens. The agent contract covers the rest, including structured data.

Does it handle Schema.org structured data?

Yes. Add data-schema to breadcrumbs, FAQs, pricing, service cards, steps, people or articles, then run npx firehorse-schema --write. It builds the JSON-LD from the page and checks that the two match.
