The 10 rules

    23 option sets

    Option sets are data: devops.option_sets (migration 435), published to schema/option-sets.json. A status option is in one of five states and takes its tone: done lime, moving sky, waiting amber, failed rose, ended neutral. A category is toned with a hue no state uses. A code set is generated from a standard and holds samples until it is. Priority is ordinal: one hue stepped in order, low to urgent.
