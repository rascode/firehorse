02 Themes

Pick a horse. The whole site changes.

A theme is a colour set: neutrals and an accent, in light and dark. It never changes type, spacing, corner radius or layout, so switching themes recolours a page without moving anything. Apply it with one attribute, data-fh-theme, and switch it with a dropdown. Shape and density stay separate choices, set with their own data-fh-* attributes.

Theme select

A native select. firehorse.js sets data-fh-theme on <html> and remembers it.

# compile it (checks AA contrast in both schemes)
npx firehorse-theme themes/appaloosa.json
# then
<link rel="stylesheet" href="themes/appaloosa.css">
<html data-fh-theme="appaloosa">
