Export

Put your canvases on any page and run npx firehorse-export page.html: each one is drawn at its native size and saved as a PNG (name it with data-fh-export or an id). Add --scale 2 for retina thumbnails. It uses Playwright, so install that once: npm i -D playwright. Every format above is also in templates/media.html, ready to edit and export.

02 Slides

Slides on reveal.js

reveal.js is the HTML slide framework developers reach for most: plain HTML, speaker notes, fragments, PDF export, MIT. A Firehorse slide is a 1280 × 720 canvas, so the same markup prints on its own or runs as a reveal deck with dist/reveal.css, and it follows your Firehorse theme and scheme without a reveal theme.

Slide layouts

Ten layouts cover most talks: title, section, agenda, text and live UI, numbers, quote, code, product screen, team and close. The avatars, chips, chat, header and datatable on them are the real components inside .fh-canvas__ui, zoomed with the slide. Each slide is a <section>, so it drops straight into reveal's .slides.
