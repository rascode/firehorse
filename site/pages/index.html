Container-native, live

One window. Three layouts. No media queries.

The window here is changing its own width on a loop. Nothing inside it knows the size of the screen; each component asks only how much room its box has, and lays itself out to match.

  • Watch the readout. The S, M and L pills light up as the window crosses 22rem and 34rem.
  • Watch the stats. Three figures sit in a row, then stack when the room runs out.
  • Watch the cards. Two columns fold into one, without a breakpoint in sight.

Hover the window to pause it. The same rules hold in a sidebar, a modal or a full-width grid.

01 Principles

Six rules the whole system follows

  1. Container-native

    Components query the slot they sit in. Viewport media queries are reserved for user preferences and print.

  2. Layered

    Nine cascade layers. Your unlayered CSS always wins, so overrides never need !important.

  3. Scheme-aware

    Every color role is a light-dark() pair. One attribute flips a page, or a single card.

  4. Native first

    <details>, <dialog> and popovers do the work. Keyboard and screen-reader behavior come from the browser.

  5. Accessible by default

    Every text token clears WCAG AA on its canvas. Focus is always visible. Motion is opt-in.

  6. Agent-ready

    Ships with an agent contract, llms.txt and a token manifest, so a coding agent builds on-system the first time.
