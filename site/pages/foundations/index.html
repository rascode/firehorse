02 Adaptive color

Text that reads its background. Math, not JavaScript.

Every text and tone token is computed from the surface under it with CSS relative color: lightness is offset from the background's own OKLCH lightness and clamped, so paint any color and the text, muted text, links and nine tones re-derive to pass contrast. The build renders 432 pairs on 18 backgrounds and fails if one drops below AA.
