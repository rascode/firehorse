# Changelog

## 1.1.0 — 2026-11-04

First public release.

- **Themes.** A theme is every design decision in one file: type, color in light and dark, radius, density, and the avatar, card, card-media, button, chip and table styles. Apply it with `data-fh-theme` on `<html>`. The `data-fh-*` presets remain as local overrides on a section.
- **Three built-in themes, named after breeds.** `mustang` (compact, square avatars, solid cards, flat buttons, zebra tables; slate and denim, condensed display), `friesian` (monochrome, square corners, outline cards, sharp buttons, underline chips, spacious; serif display), `akhal-teke` (soft corners, tonal cards, flat pill buttons, squircle avatars, borderless tables; sand and gold). `firehorse` restores the base inside a themed page. `dist/themes.css` bundles them; `dist/themes.json` lists them.
- **Theme compiler.** Themes are JSON (`src/themes/*.json`, template in `_template.json`). `scripts/gen-themes.mjs`, shipped as `npx firehorse-theme <file>.json`, expands `config` from the same presets the attributes use, tints the neutral ramp from a hue and chroma, re-derives semantic roles against the theme's palette, and fails if text, accent or on-accent drops below AA in either scheme. The build runs it.
- **Theme select.** `firehorse.js` wires any `[data-fh-theme-select]` select or radio: switches `data-fh-theme` (on `<html>` or `data-fh-theme-target`), keeps every picker in sync, remembers the choice in `localStorage["fh-theme"]`, fires `fh:theme`, and exposes `Firehorse.setTheme()`. React: `ThemeSelect` and `useFirehorseTheme()`. Index ID `THS`.
- **Layers.** Config presets moved to a new `fh.config` layer above `fh.themes`, so a `data-fh-*` attribute on a section still overrides the active theme there. Adaptive color re-evaluates on `[data-fh-theme]`.
- **Site.** A theme drawer with a dropdown and self-previewing theme cards, a theme select in the header and the mobile menu, and a Themes section. The playground's presets pick a theme, and exports carry `data-fh-theme` and its stylesheet. The Stable follows the chosen theme. Forms carry campaign attribution (UTMs, first touch, placement, page) to Rascode admin.
- **Docs site, one page per category.** The single long page is now a home page plus Foundations, Layout, Components (a hub with Actions, Content, Navigation, Overlays & feedback and Avatars), Forms, Data, Commerce, Audio, Theming, Agents and Pro. Each page opens with a breadcrumb, one title and its counts, then a floating bar whose chips are the page's component families, labelled by Index ID, with scroll spy and the rolling section title. The Docs mega, mobile menu, footer, ⌘K and the home bar are generated from the pages, `/#id` links from before the split forward to their new page, `index.json` and `agent/index.md` link each family to its page, and the build fails on a dead `#link`. Adds `sitemap.xml` and a page list in `llms.txt`.
- **Flat drawers.** The detail drawer header (`fh-detail__header`) and the overlay nav no longer paint a gradient wash; both are drawn with lines on a flat fill.

- **Adaptive color.** Text, muted text, links, status colors and all nine tones are computed from the background with CSS relative color (`tokens/adaptive.css`, generated by `scripts/gen-adaptive.mjs`). `data-fh-surface` paints any section and everything inside adapts. `scripts/verify-adaptive.mjs` renders 432 pairs on 18 backgrounds in Chromium and fails below AA.
- **Datatables.** `fh-dt` styles plus `dist/datatable.js`: 22 field types, custom types, filters, multi-sort, grouping with aggregates, field visibility, density, column resizing, selection with a bulk bar, pagination, grid/gallery/board views with drag between lanes, CSV export.
- **Panels & menus.** Floating detail drawer (`fh-dialog--float`, `fh-detail`), `fh-burger` with seven morphs and full states, `fh-overlay-nav`, `fh-command` (⌘K), menu labels/shortcuts/checks, `fh-tabbar`.
- **Commerce.** Product cards, price, swatches, sizes, quantity, gallery, product page, cart line items, shipping meter, summary, choice cards, a live payment card, card fields, express pay, checkout layout, trust row, review bars, confirmation. Defaults are plain Firehorse (etched dashed shells, mono labels and prices, tone accents), and product cards read the global card tokens. Adds `fh-product-grid` and `fh-paycard__mark`.
- **Audio.** `fh-player`, `fh-play` with a progress ring, `fh-wave` (seekable bar waveform drawn as a mask), scrubber, volume, speed, loop and skip, `fh-eq`, playlists, word-synced `fh-captions`, `fh-reel`, a multitrack `fh-mixer` with gain, mute, solo and live meters, `fh-param` readouts and `fh-stages` render progress. `dist/audio.js` wires real `<audio>`; without it the native player stays visible.
- **Motion.** `fh-rollover` heading (rolls up going forward, down going back; `Firehorse.rollover()` or `data-fh-rollover="sections"` with `data-fh-label`/`data-fh-index`). The floating bar uses it as its title. Menu, nav and chip labels use the `fh-roll` flip. The motion layer is now documented on the site (#motion), in the README and in the agent contract.
- **Fixes.** Closed popovers are always hidden (`[popover]:not(:popover-open)` in the utilities layer); a closed `.fh-mega` that also carried `.fh-frame` was staying on the page as an invisible layer that swallowed clicks. Narrow floating bars title themselves with the current section (`.fh-dock__section`). Anchors clear the header and the floating bar (`--fh-dock-height`), and a section with an id lands with its heading just below the chrome instead of its top padding. Same-page links scroll smoothly for short jumps and cut-then-glide for long ones (~400ms), update the URL and move focus; back/forward work. Sections out of view pause their time-based animations. Narrow floating bars keep two fixed rows: title with the live section, compact CTA, and a swipeable chip strip that follows the section you're in; anchors clear its measured height. The floating bar keeps one row when it engages, so it no longer grows and shifts the page (and anchor links) when it sticks. The site's hero demo window is pinned in a fixed-height stage so its animation can't move the layout.
- **The Firehorse Index.** A stable ID for every component family and variant (69 families, 81 variants): shown beside each demo, copyable with markup and agent notes, searchable on the site, published as `agent/index.md` and `index.json`, and guarded by a ledger so IDs never move.
- **KC.** The Firehorse guide: describe a component and he gives you its ID (`agent/kc.md`; answers from the index on the page, or a live endpoint via `<meta name="fh-kc-endpoint">`).
- **The Stable.** The Firehorse blog with RSS, a subscribe form and the launch post.
- **Headed mega panel.** `fh-mega--headed` puts the category titles on one row above a full-bleed etched rule with scaffold ticks, and seats the rail between full-bleed rules. `fh-mega__link` rows carry an icon or avatar, a two-line title, a role, a description and a meta line (`--compact` drops the description for long lists); `fh-mega__feature` is the rail's "Featured / name" link. Titles don't use `fh-roll`, so wrapped names never ghost. `fh-drawer__section` gives the drawer one collapsible per menu with the same groups and rows. Mega panels cap at the viewport height and scroll.
- **Dictation field.** `fh-field--dictate` lets a visitor type or talk into a textarea: a Text | Transcribe switch beside the label (the Required chip still works), and while transcribing a live caption with a waveform, clock and the words being heard, plus a plain-language error line. `dist/firehorse.js` wires any `[data-fh-dictate]` field to the browser's speech recognition (the switch hides where it can't transcribe); apps can drive the same markup themselves via `aria-pressed` and `data-listening`. Static under reduced motion.
- **Media.** `fh-canvas`: artboards laid out in a platform's real pixels (every length is a multiple of `--_u`, one native pixel), so they scale on a page and export at full size. Formats: YouTube thumbnail (`--yt-thumb`, Index `THB-01`), Open Graph link card (`--og`, `THB-02`), 4:5 feed post (`--post`, `SOC-01`), square (`--square`, `SOC-02`), 9:16 story / Reel / Short (`--story`, `SOC-03`), YouTube channel banner (`--yt-banner`, `HDR-01`), X / Bluesky header (`--x-header`, `HDR-02`), LinkedIn banner (`--li-banner`, `HDR-03`), album and podcast cover (`--cover`, `CVR-01`/`CVR-02`), business card front and back (`--card`, `BIZ-01`/`BIZ-02`). Each format's safe area is the body's inset; `data-fh-guides` outlines it and shades what the platform covers (timestamp, profile photo, app bands, grid crop). Pieces: `__top`, `__main`, `__foot`, `__title`, `__sub`, `__eyebrow`, `__mark`, `__badge`, `__index`, `__cubes` (`--rows`), `__media` (background or framed, `--round`); layouts `--center`, `--split`, `--row`; `--plate` for copy over busy art, `--plain`, `--native`. The background grid is faint by default; `--fh-canvas-grid-color: transparent` removes it. `__ui` holds real components (avatars, chips, a chat, a header, a datatable) laid out in native pixels and zoomed with the canvas; `--fh-canvas-ui-scale` enlarges them, `--crop` fades them like a cropped screenshot. New docs page, Media.
- **Slides on reveal.js.** `fh-slide` is a 1280 × 720 canvas with ten layouts (`SLD-01`…`SLD-10`: title, section, agenda, text and live UI, numbers, quote, code, close, product screen, team) and `__list`, `__stats`, `__quote`, `__cite`, `__code`, `--title`, `--section`, `--middle`. The sample slides carry the real avatar group, indexed chips, chat, header, datatable, person cards, eyebrow pill and buttons. `dist/reveal.css` (export `./reveal.css`) styles reveal.js 6 from Firehorse tokens with no reveal theme, so decks follow the active theme and scheme. The Media page has a slide builder: add, edit in place, reorder, tone, then present or download a reveal deck.
- **Patterns.** A new top-level docs page, Patterns, for page layouts with Index IDs: a live demo, an anatomy diagram, and a spec of what it's built from, what to keep, what to change freely and how it behaves on phones. Patterns are named for the parts of a saddle: Firehorse is the horse, themes are the saddles you swap, patterns are the trees they're built on. **Fender** (`FND`): a note opens a tinted band that hangs down the rest of the page through a tall footer. **Cinch** (`CIN`): a page's opening argument, claim and substance in two full-bleed panes held by one dashed line. Building blocks: offset panel (`PNL`), etched split (`ESP`, new `--roomy` modifier) and CTA band (`CTB`), moved here from Layout. The CTA band is redesigned: a short tone bar on its top edge and a faint tone fill; a split form (`__main`, `__aside`) with a display-size `__title`, fact cubes, the people you'll talk to (`__people`) and fine print (`__fine`) behind a full-height dashed seam. The simple form still works. `agent/patterns.md` is generated from the page (`scripts/patterns-docs.mjs`, part of `npm run site`), and the agent contract points to it. Each page pattern was recorded from a real page before it was rebuilt (`design/records/`).
- **Offset panel** (Index `PNL`, `src/patterns/panel.css`). A tinted column that begins at `[data-fh-panel-start]` and runs to the bottom of the page through the sections below it and the footer: the fill (the canvas at 62%) against the open canvas splits the page into two tones, and its dashed edges run the full height. `<div class="fh-panel">` is the last child of `.fh-page`; it is placed with CSS anchor positioning, and `dist/firehorse.js` places it where that isn't supported. `.fh-panel-inset` steps content off the panel's edge and keeps it inside the panel. `.fh-footer--tall` gives the footer open room to the bottom of the page (`--fh-footer-tail`). Knobs: `--fh-panel-size` (52rem), `--fh-panel-gutter` (the open strip kept on narrow screens, 3rem), `--fh-panel-fill`, `--fh-panel-pad`. Recorded in `design/records/2026-10-29-offset-panel` before it was rebuilt; the Media page uses it (page meta `"panel": true`).
- **Export and templates.** `npx firehorse-export page.html` (`scripts/export-media.mjs`, uses Playwright) saves every canvas on a page as a PNG at its native size (`--scale 2` for retina). `templates/media.html` and `templates/slides.html` are generated from the docs demos by `scripts/templates.mjs` (part of `npm run site`).
- **Hero.** An etched, galloping horse on a blueprint sheet behind the page: draws in on load, a slow band of light passes through, and it frosts over as you scroll.
- **Refinements.** `fh-stack` spaces with `gap` (a flex column) instead of sibling margins, which components were resetting from a higher layer; stacked navigation, steppers and eyebrow-led panes now keep their rhythm. The pricing flag is opaque, filled with the tier's tone and sits above the border. The tag field's radius is concentric with its chips. Datatable toolbar: one control height (`--fh-dt-control`), compact sans segmented controls, an outlined search, tool counts as tone figures, an etched action, a narrow layout; header cells use the mono label voice. The floating bar's title is a segmented eyebrow pill (live dot, section, "NN / total") that rolls and takes the section's tone.
- **Icons.** 183 Lucide icons (including a media group) as CSS masks in an optional `icons.css`; icon tiles; icons replace chip dots.
- **Chips.** `--solid`, `--tone`, `--underline`, `--indexed`, sizes.
- **Cubes and cube cards.** Cubes get their own section with `--sm`, `--xl`, `--outline` and icon cubes. New `fh-cube-card` (inline, `--stack`, trend) in `fh-cube-cards`, which walks the hue like a cube row.
- Cards: `fh-card__media`, `fh-card--cover`, token-driven border, fill, shadow and blur. Buttons: sheen and shadow tokens. `--fh-font-display` for headings.
- Enhancer: `aria-expanded` sync for popover and dialog buttons, quantity steppers, payment card formatting, command menu filtering.
- Optional React package `@rascode/firehorse-react` (Radix primitives + Firehorse classes).

## 1.0.0 — 2026-10-28

First standalone release, extracted from the rascode.dev production stylesheet.

- Token tiers: primitives → semantic (`light-dark()`) → component knobs; 196 tokens, exported as JSON, JS and TypeScript.
- Cascade layers: `fh.reset` → `fh.utilities`.
- Frame layout with named `full` / `content` lines; every slot is a query container. No viewport-width media queries.
- Components: button, action, link, roll label, dot, eyebrow pill, breadcrumb, badge, card, stats, checklist, steps, quote, crosses, accordion, tabs, dialog, menu, toast, fields, select, input group, check, switch, segmented, form layout, table (with reflow), matrix, header, nav, drawer, mega panel, footer.
- Floating bar (`fh-dock`) from rascode.dev: engages when it pins (scroll-state queries, no JS), follows the tone of the section in view, scroll-driven progress line, header CTA hand-off. Cubes that walk the tone wheel, chips, chip cards, and a floating pill bar (`fh-float`).
- New components: eyebrow-pill variants, avatars (shapes, sizes, presence, rings, halos, generated meshes, groups), person, list, timeline, chat with typing indicator, description list, kbd, divider, code block, alert, banner, progress, meter, ring, spinner, skeleton, empty state, tooltip, pagination, stepper, table of contents, sidebar nav, search, pricing tiers, feature, testimonial, logo strip, bento grid, carousel, dropzone, range, tag field, sheet.
- Optional enhancer `dist/firehorse.js`; scroll-driven motion utilities (`fh-reveal`, `data-fh-motion`).
- Patterns: hero, hero split, section head, etched split, CTA band, window, letter.
- Rascode brand theme and a theme template.
- Schema.org structured data: `data-schema` on breadcrumb, accordion (FAQ), pricing tiers, service cards, testimonials, steps, people and articles. `npx firehorse-schema` generates the JSON-LD from the visible content and fails when the two disagree. Mappings in `schema/mappings.json`; agent rules in `agent/schema.md`.
- Accessibility fixes over production: subtle text `#6e6e6e` → `#8a8a8a`, placeholder `#646464` → `#a8a8a8`, accent-as-text uses ember-400; every text role checked for AA in both schemes on each build.
- Agent contract (`agent/system.md`), generated component markup (`agent/components.md`), `llms.txt`.

- Field accessibility in the enhancer: hint and error text linked with `aria-describedby`, `aria-invalid` kept in sync with `:user-invalid`.
- `.fh-dialog` now centers itself (`margin: auto`).
