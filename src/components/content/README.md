# Content

Blocks that carry content: card, checklist, steps, stats, quote, crosses, word rotator, list, timeline, chat, description list, key value list, kbd, divider, code block, pricing tiers, features, testimonial, logo strip, bento grid, carousel, stacking deck, member card, story card, and the speed blur, dither and liquid glass effects.

Docs: https://firehorse.dev/components/content/

## Notes

Every block here is container-aware: it adapts to the slot, cell
or pane it is placed in, not to the viewport.
