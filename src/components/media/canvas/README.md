# Canvas

A canvas is a fixed-size artboard for a platform format. `base` sets up the frame, `body` the safe area, `type` the type scale on a canvas, `media` images and video, `components` real Firehorse components placed on a canvas, `layouts` the arrangements, `formats` every platform size, `wallpaper` the home-screen wallpapers on each phone's icon grid, and `guides` the safe-area overlays.

Docs: https://firehorse.rascode.dev/media/
