# Commerce

A store from the same tokens: price, product card, swatches, quantity stepper, product gallery and page, trust row, cart, choice cards, payment card, checkout, reviews, order confirmation and invoice (sheet, pay bar and payment panel).

Docs: https://firehorse.dev/commerce/

## Notes

Everything a store needs, built from the same tokens: product
cards, price, swatches and sizes, quantity, product gallery and
detail layout, cart drawer and line items, free-shipping meter,
order summary and promo code, shipping and payment choice cards,
a payment card preview and card fields, express pay, trust row,
reviews breakdown and an order confirmation.
The defaults are Firehorse: etched dashed shells, mono labels and
prices, tone accents. Product cards read the global card tokens
(data-fh-card), so the whole store restyles with the rest of the site.
