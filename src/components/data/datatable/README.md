# Datatable

The datatable, in the order it builds up: `base` (the frame and tokens), `toolbar` (title, views, search, filter/sort/group/fields panels, active filters), `grid` (scroller, header cells, group rows, footer), `bulk-actions`, `cells` (one style per field type) and `views` (gallery, board, empty and loading).

Docs: https://firehorse.rascode.dev/data/
