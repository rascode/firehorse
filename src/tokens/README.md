# Tokens

Every value Firehorse uses, as custom properties in the `fh.tokens` layer. `primitives` is the raw scale (gray ramp, tones, space, type, radius, motion), `semantic` names them by job (`--fh-color-text`, `--fh-color-surface`), `adaptive` switches them for light and dark, and `config` holds the switches themes flip (button style, density, card style).

Docs: https://firehorse.dev/foundations/
