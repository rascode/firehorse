# Admin

Operator UI, shipped as its own stylesheet (`admin.css`, load after `firehorse.css`): the app shell, environment selector, composer, dock, empty module, record header, masthead, section card, metric tiles, gauge, working indicator and tone stack. Docs: /admin/. Built for Helm.
- `app-shell.css` — App shell (SHL): sidebar + work area, env band, rail collapse.
- `env-selector.css` — Environment selector (ENV): `fh-env`, `fh-env-pill`, env menu.
- `working.css` — Working indicator (WRK): agent-on-it pill and mark.
- `empty-module.css` — Empty module (EMP-2): dashed placeholder for an unbuilt section.
- `composer.css` — Composer (CPS): chat-style capture; `--attach` for filing chips.
- `dock.css` — Admin dock (ADK): sticky working bar under the top bar.
- `tracker.css` — Tracker (TRA): a day's check-offs: head with bar and done chips, quick-add bar, check-off cards, the day's log.
