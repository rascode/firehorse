# Admin

Operator UI, shipped as its own stylesheet (`admin.css`, load after `firehorse.css`): the app shell, environment selector, thread, dock, empty module, record header, masthead, section card, metric tiles, gauge, working indicator and tone stack. Docs: /admin/. Built for Helm.
- `tracker.css` — Tracker (TRA): a day's check-offs: head with bar and done chips, quick-add bar, check-off cards, the day's log.
